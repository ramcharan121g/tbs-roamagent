# Prayanam Interaction Rules: Complete Agent Reaction & Response Contract

Refer to [docs/AGENT_REACTION_CONTRACT.md](file:///c:/Users/ramch/vignan%20hackthon%20sol/docs/AGENT_REACTION_CONTRACT.md) for full contract specification.

## Core Rules
1. **Understand, Validate, Act, Respond:** Every action or disruption must trigger state changes and explain what happens next.
2. **Deterministic Domain Authority:** Language model only parses/explains; deterministic algorithms enforce constraints, buffers, and seat locks.
3. **Explicit Consent Invariant:** No booking or itinerary alteration occurs without explicit traveller approval.
4. **Truthful Scarcity Reporting:** Never over-allocate or hide unresolved passengers.
5. **Real Outcomes:** Every button and action must interact with real domain services and persisted state.
